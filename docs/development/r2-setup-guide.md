# Cloudflare R2 Setup Guide

This guide walks you through setting up Cloudflare R2 for storing and serving product imagery and customer photo uploads for First Memoir.in.

## 1. Create the R2 Bucket

1. Log in to the Cloudflare dashboard.
2. Navigate to **R2**.
3. Click **Create bucket**.
4. Name the bucket (e.g., `first-memoir-assets`).
5. Choose your preferred location hint (e.g., APAC or Auto).
6. Click **Create bucket**.

## 2. Set Up a Custom Domain (Public Access)

We need a public URL to serve product images and resized WebP previews without presigned URLs.

1. Go to the newly created bucket settings.
2. Under **Public Access**, select **Custom Domains**.
3. Connect a subdomain (e.g., `assets.first-memoir.in` or `cdn.first-memoir.in`).
4. Wait for the DNS to provision. This will be your `R2_PUBLIC_URL` (e.g., `https://assets.first-memoir.in`).

## 3. Configure CORS for Browser Uploads

For the frontend to directly upload files to R2 via the pre-signed URL, CORS must be configured on the bucket.

1. Go to your R2 Bucket settings.
2. Scroll down to **CORS Rules**.
3. Click **Add CORS Rule**.
4. Switch to JSON editor and paste the following:

```json
[
  {
    "AllowedOrigins": [
      "http://localhost:3000",
      "https://first-memoir.in"
    ],
    "AllowedMethods": [
      "PUT",
      "GET"
    ],
    "AllowedHeaders": [
      "*"
    ],
    "ExposeHeaders": [
      "ETag"
    ],
    "MaxAgeSeconds": 3600
  }
]
```

*Note: You may adjust `AllowedOrigins` for your specific production domain or preview environments.*

## 4. Create API Tokens

1. In the R2 dashboard, click **Manage R2 API Tokens** on the right sidebar.
2. Click **Create API token**.
3. Name the token (e.g., `WePrintIt Backend`).
4. **Permissions:** Select **Object Read & Write**.
5. **Specify bucket(s):** Apply to specific buckets -> Select your newly created bucket.
6. Click **Create API Token**.
7. **IMPORTANT:** Keep the generated `Access Key ID` and `Secret Access Key` open; they are only shown once!

## 5. Configure Lifecycle Rules (Crucial for Costs)

Customers may abandon their uploads or remove items from their carts. We want R2 to automatically delete abandoned raw customer photos to save storage costs.

1. In your Bucket settings, navigate to **Object Lifecycle Rules**.
2. Click **Add rule**.
3. Name the rule: `Delete abandoned customer uploads`.
4. Add a prefix condition: `customers/`.
5. Under **Action**, select **Delete object**.
6. Set the age to `1 day` (24 hours).
7. Save the rule.

*Note: Previews generated by the backend and placed in the `previews/` folder will not be affected by this rule. They will be managed later by the Order completion flow or a separate cleanup script.*

## 6. Update Environment Variables

Add the following to your `apps/api/.env` file:

```env
# Cloudflare R2
R2_ACCOUNT_ID="your_account_id_from_cloudflare_dashboard_url"
R2_ACCESS_KEY_ID="your_access_key_id"
R2_SECRET_ACCESS_KEY="your_secret_access_key"
R2_BUCKET_NAME="first-memoir-assets"
R2_PUBLIC_URL="https://assets.first-memoir.in"
```
